      02 The rating matrix

      03 Rating prediction is not ranking

      On the full dataset, MatrixFactorization minimises squared error on observed ratings — the classic Netflix-prize objective — and scores well at exactly that. Ranked by its predicted rating it collapses: the highest predictions go to items a handful of generous users rated 5, which almost nobody else wants.

      BPR is the same architecture with the ratings thrown away. For each thing a user interacted with, sample something they did not, and push the first above the second. Same factors, same regularisation, same data: NDCG@10 0.0138 → 0.1878, a factor of thirteen.

      Also fixed in the package: a temporal split per user (never random), seen items excluded from every page, and coverage reported next to accuracy — popularity reaches 10.7% of the catalogue; BPR reaches 97%.
